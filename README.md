# LED-Match-Game 灯带消消乐
A Match-3 game implemented with ESP32-C3 and WS2812 LED strips.

这是一个基于ESP32的LED灯带游戏系统，通过WiFi提供网页控制界面，实现了老虎与大象对战的互动游戏，支持多设备通信、音效、动画效果以及中英文双语界面.

项目依赖库与技术栈

核心依赖库 ：
- FastLED ：用于控制WS2812B灯带，实现灯光动画效果
- WiFi ：提供网络连接能力，支持设备间通信
- WebServer ：构建网页服务器，提供参数配置界面
- esp_now.h ：实现ESP-NOW协议通信，支持主控/从机设备间快速数据传输
- Preferences ：用于非易失性存储，保存38个游戏参数
  
主要技术 ：
- 基于ESP32平台，使用Arduino框架开发
- 网络通信：通过WiFi建立AP模式，支持设备发现与自动角色竞选（主控/从机）
- 网页技术：HTML5 + CSS + JavaScript，实现响应式配置界面
- 音效系统：Web Audio API生成游戏音效和背景音乐
- 物理引擎：自定义碰撞检测与运动逻辑
- 渲染引擎：优化的灯带显示算法，支持亮度突破和颜色叠加
  
项目特点
1. 多设备协同 ：支持自动角色竞选（10秒扫描），可作为主控或从机运行
2. 丰富的游戏模式 ：普通模式（盾牌防御）、节奏模式（颜色匹配）、混合模式
3. 自定义参数 ：38个可调节参数，支持亮度、速度、难度等精细调整
4. 高级攻击机制 ：波次扫射攻击，随关卡提升概率增加
5. 多语言支持 ：中文/英文双语界面，一键切换
6. 移动设备优化 ：针对iOS设备的触摸事件处理，防止双击/双指缩放
7. 沉浸式体验 ：动态音效、呼吸动画、胜利/失败特效
   
游戏实现原理
核心玩法 ：
- 老虎 ：从右侧发射彩色子弹，随关卡提升速度和密度
- 大象 ：位于左侧，被子弹击中后老虎前进
- 玩家 ：通过物理按钮或网页按钮生成对应颜色的盾牌（普通模式）或进行节奏匹配（节奏模式）
- 胜利条件 ：老虎被击退至起始位置或完成节奏模式目标击中数
- 失败条件 ：老虎到达大象位置
  
技术实现 ：
- 物理引擎 ：实时更新子弹位置、碰撞检测、老虎移动逻辑
- 渲染引擎 ：逐帧绘制灯带画面，包括大象、子弹、盾牌、老虎和特效
- 状态管理 ：通过状态机控制老虎休息、攻击波次、长休奖励等状态
- 事件系统 ：通过事件队列与网页通信，触发音效和动画
- 参数持久化 ：使用Preferences存储用户配置，重启后保持设置
  
项目通过模块化设计，将硬件控制、网络通信、游戏逻辑和用户界面分离，实现了一个功能完整、交互丰富的LED灯带游戏系统。
